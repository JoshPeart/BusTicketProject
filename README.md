# BusTicketProject
<ul>A user interface to the NCTX bus tickets</ul>

<strong>
<h1>Use Case 1 - General Introduction</h1>
</strong>
<ul>Displaying a welcome message and a list of options to the user</ul>
<ul>Store those options in a list of strings</ul>

<strong>
<h1>Use Case 2 - User Input & CSV Data Lookup</h1>
</strong>
<ul>Ask user to enter option number</ul>
<ul>Validate number is within the range of options</ul>
<ul>Read file (mobile_products.csv)</ul>
<ul>filter tickets belonging to that category</ul>
<ul>Display the results to the user</ul>

<strong>
<h1>Use Case 3 - Display Tickets by Category</h1>
</strong>
<ul>After the user selects a ticket category, the program shows all tickets in that category, including title, description, and price.</ul>
<ul>Display Price in Pounds (£) rather than pence</ul>

<strong>
<h1>Use Case 4 - Filtering Options</h1>
</strong>
<ul>creates a seperate dropdown menu with options for the user to fileter results, depending on wether they want to filter by price, bulkbuy tickets, or by age</ul>
